Нужен ключ Yandex Maps JS API

Этот пример рисует карту официальным Yandex Maps JS API 2.1. Для работы нужен бесплатный ключ из Кабинета разработчика Яндекса (тип «JS API и Геокодер по HTTP»).

  1. Получите ключ и добавьте его в .env сервера: 
    YANDEX_JS_KEY=ваш-ключ-js-api
YANDEX_GEOCODER_KEY=ваш-ключ-геокодера   # поиск адресов (опционально)
YANDEX_ROUTER_KEY=ваш-ключ-маршрутов     # честные км/мин с пробками (опционально)
  2. Перезапустите npm start и обновите страницу.

Без ключей основное демо на главной странице продолжает работать (локальный граф дорог OSM + модель пробок).

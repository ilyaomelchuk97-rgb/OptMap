# OptMap — офлайн-карта с адресами, дорогами и маршрутами

Полностью автономная картографическая платформа: векторные тайлы, поиск по
адресам/улицам/объектам, обратный геокодинг и построение маршрутов — **всё
работает без интернета**, из локальных файлов.

Демо-регион: **Монако** (реальные данные OpenStreetMap).

```
┌─────────────┐   .osm.pbf    ┌──────────────────────────────┐
│  Geofabrik  │ ────────────► │  pipeline/ (Python)          │
│  (любой      │               │  · тайлы MVT  data/tiles/    │
│   регион)    │               │  · индекс    data/index.json │
└─────────────┘               │  · подписи   data/labels.json│
                              │  · граф      data/graph.json │
                              └──────────────┬───────────────┘
                                             │
                              ┌──────────────▼───────────────┐
                              │  server/ (Node.js, 0 завис.) │
                              │  статика + /api/...          │
                              └──────────────┬───────────────┘
                                             │
                              ┌──────────────▼───────────────┐
                              │  web/ (MapLibre GL JS)       │
                              │  карта, поиск, маршруты      │
                              └──────────────────────────────┘
```

## Почему не «копия Яндекс.Карт»

Технически и юридически скопировать Яндекс.Карты нельзя: их данные —
коммерческая собственность, выгрузки не предусмотрены, API требует интернета
и ключа, а тайлы защищены. Поэтому OptMap делает то же самое, но на открытых
данных **OpenStreetMap (лицензия ODbL)** — их можно свободно скачать,
обработать и использовать офлайн. Это не «бедная версия»: в OSM те же адреса,
дороги, здания, POI и границы — просто вы становитесь владельцем своих данных.

## Быстрый старт

```bash
# 1. данные (уже собраны для Монако, лежат в data/)
#    если data/ пустая — см. «Свой регион» ниже

# 2. сервер (нужен только Node.js >= 18)
node server/server.js                 # http://localhost:8080
node server/server.js --port 3000     # другой порт
```

Откройте http://localhost:8080 — карта, поиск, маршруты. Интернет не нужен.

## Что умеет

| Возможность | Детали |
|---|---|
| Карта | векторные тайлы, зум 11–18, суша/море/парки/здания/дворы, иерархия дорог, туннели, мосты, ж/д, границы |
| Подписи | города, районы, улицы, водоёмы, парки, POI, номера домов — со своим движком коллизий |
| Поиск | адреса («Бульвар Альбера 1er, 5b»), улицы, POI, населённые пункты; русские названия где есть |
| Обратный геокодинг | клик по карте → что находится рядом |
| Маршруты | авто и пешком, Дейкстра по графу дорог, длины/время, пошаговые инструкции с поворотами |
| Офлайн | ноль внешних запросов: тайлы, индекс, граф, шрифты — всё локальное |
| Темы | светлая и тёмная |

## Свой регион (любой город/страна)

```bash
# 1. скачайте выгрузку .osm.pbf (например с geofabrik.de)
wget https://download.geofabrik.de/europe/monaco-latest.osm.pbf

# 2. соберите карту
pip3 install osmium pillow          # зависимости конвейера
python3 -m pipeline.build \
    --input monaco.osm.pbf \
    --name Monaco --name-ru "Монако" \
    --out data --minz 11 --maxz 18

# 3. запускайте сервер — он подхватит новый регион автоматически
node server/server.js
```

Зумы подбираются под размер региона: для города хватает 11–18, для страны —
`--minz 4 --maxz 16` (иначе тайлов будет слишком много).

## Как это устроено

### Конвейер (`pipeline/`, Python)

| Файл | Назначение |
|---|---|
| `osm_model.py` | чтение `.osm.pbf` через pyosmium, плоская модель: узлы, пути, связи (мультиполигоны, границы), сборка колец |
| `mvt.py` | кодировщик Mapbox Vector Tile на чистом Python (protobuf + gzip), без зависимостей |
| `tiles.py` | проекция Web Mercator, клиппинг геометрии по тайлам, распределение объектов по слоям и зумам |
| `search_index.py` | индекс адресов / улиц / POI / образцов улиц для обратного геокодинга |
| `routing_graph.py` | граф дорог с классами, односторонними, скоростями |
| `labels.py` | плоский файл подписей для HTML-движка на клиенте |
| `preview.py` | статичное PNG-превью региона без запуска сервера |

Тайлы складываются как `data/tiles/{z}/{x}/{y}.pbf.gz` — обычные файлы,
никакой СУБД не нужно.

### Сервер (`server/server.js`, Node.js, ноль зависимостей)

| Эндпоинт | Ответ |
|---|---|
| `GET /` | веб-приложение |
| `GET /api/config` | метаданные региона (центр, границы, зумы, статистика) |
| `GET /api/tiles/{z}/{x}/{y}` | векторный тайл (gzip) |
| `GET /api/labels` | подписи для клиента |
| `GET /api/search?q=` | результаты поиска |
| `GET /api/reverse?lon=&lat=` | обратный геокодинг |
| `GET /api/route?a=lon,lat&b=lon,lat&mode=car\|foot` | маршрут: геометрия, шаги, инструкции |

### Клиент (`web/`)

MapLibre GL JS (полностью скопирован в `web/vendor/`, CDN не используется) +
слой подписей на HTML/DOM с собственной расстановкой и разрешением коллизий,
тёмная/светлая тема, шкала масштаба, координаты.

## Проверка

```bash
python3 tests/check_layers.py            # все слои стилей есть в тайлах
node tests/check_tiles.js data/tiles     # каждый тайл декодируется (нужен npm i @mapbox/vector-tile pbf)
```

## Размеры данных (Монако)

```
data/tiles/      ~19 МБ   4902 тайла (зум 11–18)
data/index.json  ~0.4 МБ  4202 записи (1145 видимых)
data/labels.json ~0.15 МБ 1652 подписи
data/graph.json  ~3.6 МБ  26 016 узлов, 50 275 рёбер
data/preview.png          статичное превью региона
```

Каталог `data/` не хранится в git — он генерируется конвейером из любого
`.osm.pbf`. Исходник (`data/monaco.osm.pbf`) скачан один раз.
